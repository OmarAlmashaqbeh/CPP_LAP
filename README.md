## 📌 وصف المستودع

هذا المستودع يحتوي على حلول (Lab Sheets) لمادة **مختبر مقدمة في البرمجة (Introduction to Programming Lab)**  
في الجامعة الهاشمية، وهو مخصص لمساعدة الطلاب على:

- تعلم أساسيات لغة C++
- فهم إدخال وإخراج البيانات باستخدام:
  - `cin`
  - `cout`
- استخدام العمليات الحسابية (Arithmetic Operators)
- تطبيق الجمل الشرطية (if / switch)
- استخدام الحلقات (loops)
- كتابة الدوال (Functions)
- فهم المصفوفات (Arrays)
- التمييز بين:
  - Call by Value
  - Call by Reference

---

## 🧠 ماذا ستتعلم؟

من خلال هذا المستودع ستتعلم:

- أساسيات لغة C++
- استخدام `cin` و `cout`
- العمليات الحسابية والتحويلات
- الجمل الشرطية والتفرعات
- الحلقات (for, while, do-while)
- التعامل مع Strings
- إنشاء واستخدام Functions
- Function Overloading
- Call by Value vs Call by Reference
- التعامل مع Arrays

---

## 🧪 محتوى المختبر

ينقسم المختبر إلى عدة أجزاء:

- **Lab 1:** أساسيات C++ (Input / Output)
- **Lab 2:** العمليات الحسابية
- **Lab 3:** الجمل الشرطية (Selection)
- **Lab 4:** الحلقات (Loops)
- **Lab 5:** الدوال (Functions)
- **Lab 6:** Function Overloading
- **Lab 7:** Call by Value & Reference
- **Lab 8:** Arrays
